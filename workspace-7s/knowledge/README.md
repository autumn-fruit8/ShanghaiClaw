# Knowledge — Data & Reference

Regeneratable price data, research notes, and bug logs for the 7S engine.

## Structure

```
knowledge/
├── README.md           ← This file
├── articles/            Strategy / design notes (markdown)
├── cn/                  China-market data
│   ├── 1_raw/           Raw downloads (not version-controlled)
│   ├── 3_processed/     Cleaned price CSVs per symbol (daily close, adjusted)
│   ├── 4_archive/       Historical raw snapshots (xlsx, xls, processed CSVs)
│   └── logs/            Daily update logs (per execution date)
├── us/                  US-market data
│   ├── 1_raw/
│   ├── 3_processed/     Cleaned price CSVs per symbol
│   ├── 4_archive/       Historical raw snapshots (html, xlsx, mhtml)
│   └── logs/            Daily update logs
└── *.md                 Cross-market notes (bug logs, audit docs)
```

## Convention

- **`3_processed/`** — canonical price data consumed by the strategy engine. Auto-regenerated by `data-daily-update`.
- **`4_archive/`** — historical raw data from initial calibration. Kept for reproducibility but not needed for daily operation.
- **Logs** — execution logs from the daily update pipeline. Kept for debugging.
- **Articles** — long-form design notes, not auto-generated.

## Ignored from git

The entire `knowledge/` directory is gitignored — all data is regeneratable from upstream sources via the daily update pipeline. This keeps the repo lightweight and avoids tracking stale or large binary files.
