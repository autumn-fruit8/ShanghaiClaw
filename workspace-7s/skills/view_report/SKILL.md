# Report Push Skill

## Human Triggers

**Keyword**: `report`

**When to trigger**: Human wants Feishu-delivered output — daily/weekly market summary with charts.

**Natural Language** (exclusive territory — do NOT overlap with `analyze`/`decide`/`review`):

| Intent | What to say |
|--------|-------------|
| Daily push | *"今日报告"* / *"发日报"* / *"推送今日报告"* |
| Weekly push | *"本周报告"* / *"发周报"* / *"推送周报"* |
| Specific region | *"发一份 A 股日报"* / *"美国市场的报告"* |
| Dry run preview | *"先预览一下报告"* / *"看看报告草稿"* |
| Skip market map | *"只发文字报告"* |

**Cross-skill routing**:
- Want **live signals**? → use `analyze`: *"分析今天的市场信号"*
- Want **drift decision**? → use `decide`: *"cn_hb 需要调仓吗"*
- Want **historical performance**? → use `review`: *"看看 us_hb 的历史收益"*
- This skill is for **formatted delivery only** — not for computing signals

## Input Contract

Expected inputs:

- report type: `daily` or `weekly`
- optional region filter
- existing strategy snapshots under `logs/positions/`
- Feishu delivery configuration unless `--dry-run` is used

This skill is delivery-oriented. It should not be used as the place to compute raw strategy signals.

## Workflow

1. **Strategy** should already be run (generates snapshots in `logs/positions/`)
2. **Generate report** using `report_pusher.py`
3. **Send to Feishu** as Markdown + PNG market map

## Usage

```bash
# Daily report
python3 skills/view_report/scripts/report_pusher.py --type daily

# Weekly report  
python3 skills/view_report/scripts/report_pusher.py --type weekly

# Specific region
python3 skills/view_report/scripts/report_pusher.py --region cn --type daily

# Specific date
python3 skills/view_report/scripts/report_pusher.py --region cn --type daily --date 2026-05-27

# Dry run (no Feishu push)
python3 skills/view_report/scripts/report_pusher.py --dry-run

# Skip market map
python3 skills/view_report/scripts/report_pusher.py --skip-map
```

## Output Contract

- Markdown report: `logs/reports/{date}_{type}_report_{region}.md`
- Market map PNG: `logs/reports/{date}_market_map_{region}.png`
- Feishu push result when not using `--dry-run`

## Cron Schedule

This skill is triggered automatically via OpenClaw cron jobs (not via HEARTBEAT.md):

- Daily: 8:00 AM Beijing, Tue-Sat
- Weekly: Sunday 9:00 AM Beijing

See `~/.openclaw/cron/jobs.json` for full configuration.

## Error Handling

- If no snapshots: Report data status as stale/error (still pushes)
- Always push (even if data is old)
- Market map generation is optional (--skip-map)

## Report Structure

### Daily Report — Signal Overview + Detail Table
Answers: "今天市场怎样？"
- Signal distribution per region (BULLISH/NEUTRAL/OPPORTUNITY/WARNING/BEARISH/DANGER)
- Full asset table with signal, LDev, RSI
- Market map scatter plot (LDev vs MA60%)
- Data freshness status

### Weekly Report (Vector) — Week-over-Week Comparison
Answers: "本周的证据是否改变了我下周该做的事？"
4 sections:

1. **✅ 我的计划在正轨上吗？**
   - Plan progress table per HB plan: last week weight → this week weight → Δweight → target → direction emoji
   - Build progress % (current value / target)
   - Direction indicates if weight is approaching (🟢) or diverging (🔴) from target

2. **📊 资产信号向量：变好还是变坏？**
   - Sort by |ΔLDev| descending (biggest changes first)
   - Per asset: last LDev → now LDev → ΔLDev → MA60% → signal class transition
   - Notable transitions marked: 🟡 new OPPORTUNITY, 🟢 new BULLISH, 🔴 new DANGER

3. **⚡ 本周关注事项**
   - Three-tier attention list generated by rule engine:

     | Level | Criteria |
     |-------|----------|
     | 🔴 紧急 | DANGER 连续2周，新入 DANGER，LDev 单周降>0.5σ，MA60 支撑跌破 |
     | 🟡 值得关注 | 新 OPPORTUNITY/BULLISH，LDev Δ>0.3σ（双向），WARNING/BEARISH 持续2周，MA60 向上突破，MA60 偏离度变化>1.5% |
     | 🟢 机会观察 | 新入 Deep Value 区（LDev<-1.5σ），RSI 进入超买>90 或超卖<30 |

   - Items are not repeated across tiers

4. **📋 概览汇总**
   - Signal distribution comparison: this week vs last week (delta in parentheses)
   - Asset count per region

### Market Map
- Scatter plot: LDev vs MA60% by asset type
- Generated for daily reports; optional for weekly

## Features

- **Vector comparison**: Week-over-week signal direction (LDev delta, signal class transition, MA60 crossover detection)
- **Modeless**: 4 sections, skip-empty section if no data
- **Markdown format**: Clean, readable in Feishu without PDF attachment
- **Market map PNG**: Scatter plot of LDev vs MA60% by asset type
- **Decoupled**: Push still works even if update/strategy fails
- **Flexible**: --dry-run, --skip-map, --region flags
