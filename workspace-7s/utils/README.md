# Utilities — workspace-7s

Shared helper modules used across skills and infrastructure.

## Modules

| Module | Purpose |
|--------|---------|
| `data_service/` | External API clients, CSV resolver, bond yield service |
| `formatting/` | Output formatters (markdown, view builder) |
| `indicators/` | Technical indicators (LDev, RSI, Z-score, trend utilities) |
| `preprocess/` | Data preprocessing and calibration |
| `symbols/` | Symbol resolution, state resolution, bootstrapping |
| `validation/` | Input validation and data integrity checks |
| `constants.py` | Shared constants |

Each module has its own README for detailed documentation.
